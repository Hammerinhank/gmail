👋 Bienvenue : configurons l’accès à Gmail

Pour que cette application puisse lire et trier vos mails, Google exige que vous créiez votre propre « identifiant client OAuth » (c’est gratuit, 5 minutes). Il suffit de suivre les 5 étapes ci‑dessous.

Bon à savoir : il n’y a pas de clé API ni de « secret » à copier. Seul l’ID client est nécessaire. Il est enregistré uniquement dans le localStorage de votre navigateur : rien n’est envoyé à un serveur tiers, et le code ne contient aucun secret.
⚠️ Vous avez ouvert ce fichier directement (file://). Google refuse la connexion dans ce cas. Lancez un petit serveur local : dans le dossier du fichier, tapez python3 -m http.server 8000 puis ouvrez http://localhost:8000/menage-gmail.html.

Journal GitHub (optionnel)

Chaque suppression est notée dans un fichier JSON de votre dépôt GitHub : date, catégorie (pour un expéditeur : seulement son domaine), nombre de messages, totaux après nettoyage. Aucun contenu de mail. Sans GitHub, le journal reste dans ce navigateur. Les mesures du graphique « Répartition par boîte » (nombres de messages par catégorie, rien d’autre) sont dans un second fichier, menage-gmail-repartition.json, du même dépôt. Chaque compte Gmail a son propre dossier dans ce dépôt, nommé d’après son adresse : les données de plusieurs comptes ne sont jamais mélangées.

Comment ça marche ? (durée, reprise, rangs)
  • Une requête par message : environ 1 minute pour 3 000 messages (limite Gmail ≈ 50 messages/s). Gardez l’onglet visible.
  • L’analyse peut être arrêtée puis reprise ; son résultat est mémorisé sur cet ordinateur (localStorage).
  • Les rangs se décalent quand de nouveaux mails arrivent ou après un nettoyage.
  • Pour explorer une zone ancienne (par exemple du rang 50 000 au rang 60 000), Gmail doit d’abord lister tous les messages jusqu’au rang de fin : environ 1 minute pour 60 000.

Expéditeurs

À quoi servent les boutons Scannés, Tous et Info ?

Scannés : ne met à la corbeille que les messages identifiés lors de l’analyse affichée. Tous : met à la corbeille tous les messages de l’expéditeur dans le périmètre de la liste déroulante, y compris hors de la zone analysée. L’ancienneté minimale de l’analyse affichée s’applique aussi à la suppression : les mails plus récents ne sont jamais touchés. Le champ de recherche filtre tous les expéditeurs (pas seulement les 50 premiers). Les garde-fous de suppression (étoilés et importants épargnés par défaut ; libellé personnel et pièce jointe en option) valent pour tous les boutons de suppression. Le tri « Taille (Mo) » classe les expéditeurs par poids total de leurs mails scannés (analyses faites avec cette version ou une suivante). Le tri « Mails non lus » classe les expéditeurs par inutilité à partir de l’analyse, avec pour chacun la part de non lus, les favoris, l’onglet Gmail dominant, la désinscription possible et si vous lui avez déjà écrit. Quand l’analyse est partielle (rang de début supérieur à 1, rang de fin renseigné ou analyse incomplète), chaque expéditeur affiche « scannés / total dans le périmètre » : la valeur du bouton choisi (« Mails scannés » ou « Total dans le périmètre ») est en noir, l’autre en gris. Quand l’analyse couvre tout le périmètre, les deux nombres sont identiques et ce choix est masqué. Info affiche une ligne par bouton (Voir, Voir scannés, Scannés, Tous) avec le nombre exact de mails concernés et ce que ce nombre mesure, pour ne pas être surpris par ce que Gmail affichera ou par ce qui sera supprimé. Passez la souris sur un bouton pour le détail.
